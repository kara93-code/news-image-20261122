## Run it

```sh
python3 main.py
```

The program copies the bundled front page (`assets/entry.jpg`,
1024×1024 JPEG, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`), checking its JPEG header and dimensions first.
Python 3.13, standard library only, no network. Two runs write
identical bytes.
